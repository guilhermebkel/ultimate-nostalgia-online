# Domain docs

- `GLOSSARY.md` has the vocabulary and the words to avoid. Use its terms in code, docs and issues.
- `docs/adr/` has one record per decision someone could undo without knowing why. Read the ones that touch the area before changing it; change one only by adding a new record that replaces it.
- `design/README.md` has the logo rules (clear space, minimum size, the colors) and the trademark warning about the name.
